# Changelog

## 2026.10.30.1 — 30 October 2026

First standalone public repository for the Legiscope European privacy-fines study.

- Frozen published dataset: 1,042 documented decisions across ten countries; source collection as of 25 October 2026.
- Includes the source-audit corrections published on 30 October 2026 and retains that public audit record.
- Country extracts, source index, classification bridge, data dictionary and reproducible country calculations.
- Executed analysis notebook and reusable SVG/PNG charts.
- Publication handoffs for data portals, chart tools and archival reuse.
- Original data and documentation under scoped CC BY 4.0; original software under MIT.

This release preserves the published snapshot and its source limitations. It introduces no new comprehensive legal audit or national-coverage claim.
