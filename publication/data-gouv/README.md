# data.gouv.fr: French decisions

1. Use the real Legiscope account/organization and create a dataset draft.
2. Copy the prepared title, description, tags and update-frequency information from `metadata.json`.
3. Choose the applicable CC BY 4.0 licence for the original contributions and retain the third-party source exceptions.
4. Upload `fr-cases.csv`, `fr-data.json` and `fr-themes.csv`, or use the versioned resource URLs in the metadata.
5. Check the rendered description and resources, including the source and methodology links, then publish.

`metadata.json` is an editor handoff, not an already-submitted API payload. It does not invent an organization ID.

Official guide: <https://guides.data.gouv.fr/jeux-de-donnees/publier-un-jeu-de-donnees>

Study and source attribution: <https://www.legiscope.com/blog/europe-data-protection-fines-per-capita.html>

Exact release and licence scope: <https://github.com/legiscope/gdpr-data-study/tree/v2026.10.30.2>

The French selection contains 200 documented decisions. It includes related data-protection regimes, not exclusively GDPR, and is not a complete national census. Themes are multi-label and must not multiply monetary totals.
