# Flourish chart data

Import `amounts-per-resident.csv` for the country calculation or `france-themes.csv` for the French theme frequencies. Choose a native template, bind the columns and inspect its desktop/mobile rendering before publication.

Retain known/unknown monetary coverage, the collection date and the population reference. Countries cover different periods and legal regimes. The French theme table has multiple possible themes per case and a within-France denominator; it must not be interpreted as comparable national offence rates.

Use the public study as the source link: <https://www.legiscope.com/blog/amendes-rgpd-europe-comparaison-pays.html>.
