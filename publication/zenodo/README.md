# Zenodo deposit

Build the complete archive with `python3 scripts/build.py --package` at the repository root. Upload `gdpr-data-study-2026.10.30.2.zip` as the deposit's reproducible research bundle. Use `metadata.json` for the deposit form/API or `.zenodo.json` at the repository root for a separately configured GitHub integration.

Verify the actual creator account, organization, licence, version and publication date before publication. If the deposit is published after 30 October, set its publication date to the actual date. This package does not assign a DOI or enable an integration.

After publication, record the real DOI in the citation metadata and link the deposit back to the study and exact source version. The data/documentation licence is CC BY 4.0 for original Legiscope contributions; the original code remains MIT and third-party source terms remain applicable.
